# Плагины FastAction

Плагин — это вкладка в челке, написанная на JavaScript. Он не получает доступ ни к файлам,
ни к сети, ни к другим плагинам: всё, что ему доступно, — объект `fa`, и каждый вызов там
проверяется дважды: объявлено ли это в манифесте и разрешил ли это пользователь.

Плагины не входят в приложение. «Jira» и «1Password» мы публикуем сами — они ставятся из
**Настройки → Плагины** одним нажатием, написаны на этом же API и работают в той же песочнице:
никаких особых прав у них нет.

## Быстрый старт

```
weather.fastplugin/
  manifest.json
  plugin.js
```

`manifest.json`:

```json
{
  "id": "com.example.weather",
  "name": "Погода",
  "caption": "ПОГОДА",
  "icon": "cloud.sun",
  "summary": "Погода за окном в челке.",
  "version": "1.0.0",
  "author": "Example",
  "permissions": { "network": ["api.open-meteo.com"] },
  "settings": [
    { "key": "city", "type": "string", "title": "Город", "default": "Москва" }
  ],
  "refreshMinutes": 15
}
```

`plugin.js`:

```js
let temperature = null;

fa.plugin({
  async load(env) {
    this.city = env.settings.city || 'Москва';
    await this.refresh();
  },

  async refresh() {
    const response = await fa.http.get(
      'https://api.open-meteo.com/v1/forecast?latitude=55.75&longitude=37.62&current=temperature_2m'
    );
    temperature = response.json && response.json.current
      ? response.json.current.temperature_2m : null;
  },

  render() {
    return [
      { type: 'header', title: this.city, actions: [{ action: 'refresh', icon: 'arrow.clockwise' }] },
      { type: 'text', value: temperature === null ? '—' : temperature + ' °C', style: 'title' },
    ];
  },

  async action(id) {
    if (id === 'refresh') { await this.refresh(); }
  },
});
```

Выберите папку (или zip-архив с ней) в **Настройки → Плагины → Установить плагин…** и разрешите
запрошенное — вкладка появится в панели. Установленные плагины лежат в
`~/Library/Application Support/FastAction/Plugins/`.

## manifest.json

| Поле | Обязательное | Описание |
|---|---|---|
| `id` | да | Только строчные латинские буквы, цифры, точка и дефис. Становится пространством имён в связке ключей и именем папки данных. |
| `name` | да | Название в настройках и в списке вкладок. |
| `icon` | да | Имя SF Symbol. Несуществующее имя заменяется нейтральным значком. |
| `caption` | нет | Подпись в шапке панели, обычно капсом. По умолчанию — `name` капсом. |
| `summary` | нет | Одна строка описания для страницы настроек. |
| `version`, `author` | нет | Показываются пользователю. |
| `apiVersion` | нет | Версия API, под которую написан плагин (сейчас `1`). Плагин с бо́льшим числом не запустится. |
| `entry` | нет | Имя скрипта, по умолчанию `plugin.js`. |
| `integrity` | нет, но желательно | `{"plugin.js": "sha256-<хеш>"}`. Если файл не совпадает с хешем, плагин не загрузится. |
| `permissions` | нет | См. ниже. Чего нет в манифесте — того плагин не получит никогда. |
| `settings` | нет | Схема формы настроек; форму рисует хост. |
| `refreshMinutes` | нет | Как часто вызывать `refresh()` в фоне. Минимум — 1 минута. |

### permissions

```json
"permissions": {
  "network": ["*.atlassian.net", "$setting:site"],
  "secrets": true,
  "clipboard": true,
  "notifications": true,
  "openURL": true,
  "autofill": false,
  "exec": [{ "tool": "op", "reason": "Читать записи через официальный CLI" }]
}
```

- **`network`** — список хостов. Поддерживается маска `*.example.com` и `$setting:<ключ>` — хост,
  который пользователь сам введёт в поле настроек типа `host`. Разрешён только `https`.
  Редирект на хост вне списка обрывается.
- **`secrets`** — своё пространство в связке ключей (`app.fastaction.plugin.<id>`). Чужие записи не видны.
- **`clipboard`** — запись в буфер обмена. Чтения буфера нет ни у кого.
- **`notifications`** — уведомления в челке; они подчиняются общим настройкам приложения
  (время показа, звук, режим фокусирования).
- **`openURL`** — открыть `http(s)`-ссылку в браузере по клику пользователя.
- **`exec`** — запуск программы из короткого списка известных хосту (сейчас только `op`).
  Никакой оболочки: аргументы передаются как argv.
- **`autofill`** — ввод логина и пароля в активное приложение по явной команде пользователя.

### settings

```json
{ "key": "site", "type": "host", "title": "Адрес Jira", "placeholder": "company.atlassian.net",
  "help": "Единственный адрес, куда плагину разрешено обращаться" }
```

Типы: `string`, `secret`, `host`, `bool`, `number` (с `min`/`max`), `select` (массив `options`,
элемент вида `"значение|Подпись"`), `jql` (многострочное поле).

Значения приходят в `load(env)` как `env.settings`. Исключение — `secret`: такие поля
не попадают в `env.settings`, их читают через `fa.secrets.get(<ключ>)`.

## Жизненный цикл

Плагин регистрируется один раз:

```js
fa.plugin({ load, refresh, render, action });
```

| Метод | Когда вызывается | Может быть async |
|---|---|---|
| `load(env)` | при запуске и после изменения настроек | да |
| `refresh()` | при открытии вкладки и по таймеру `refreshMinutes` | да |
| `render()` | после каждого `load`, `refresh` и `action` | нет, должен быть быстрым |
| `action(id, payload)` | по клику или вводу в поиск | да |

`env` содержит: `settings` (значения формы), `locale` (`ru`, `en`, `es`, `de`, `fr`),
`tools` (какие объявленные программы установлены), `apiVersion`.

Состояние плагин держит у себя в модуле; между запусками его можно сохранять через `fa.storage`.

## Описание экрана

`render()` возвращает массив узлов. Хост рисует их своими средствами — плагин не может нарисовать
произвольный интерфейс, всплывающее окно или что-то похожее на системный запрос пароля.

```js
{ type: 'header', title: 'Мои задачи', subtitle: '12',
  actions: [{ action: 'refresh', icon: 'arrow.clockwise', help: 'Обновить' }] }
{ type: 'search', placeholder: 'Поиск', value: query, action: 'search' }   // payload: { query }
{ type: 'input', label: 'Ссылка', placeholder: 'https://…', value: '', submit: 'Добавить',
  action: 'link', secret: false }                                          // payload: { text }
{ type: 'text', value: 'Любой текст', style: 'title' | 'body' | 'caption' | 'mono' }
{ type: 'section', title: 'Комментарии', children: [ ... ] }
{ type: 'list', rows: [ {
    id: 'ABC-1', icon: 'circle.fill', iconTint: 'orange',
    title: 'ABC-1', subtitle: 'Починить панель', trailing: '2 ч',
    badges: [{ text: 'In Progress', tint: 'blue' }],
    tap: 'open:ABC-1',
    actions: [{ action: 'copyKey:ABC-1', icon: 'number', help: 'Скопировать номер' }],
} ] }
{ type: 'field', label: 'Пароль', value: '…', secret: true, copy: 'copyField:password' }
{ type: 'button', title: 'Автозаполнить', icon: 'keyboard', action: 'autofill' }
{ type: 'buttons', items: [ ... ] }
{ type: 'empty', icon: 'key', title: 'Записей нет', subtitle: '…',
  action: { title: 'Показать', action: 'unlock' } }
{ type: 'progress', text: 'Загружаем…' }
{ type: 'note', icon: 'info.circle', text: 'Пояснение', tint: 'gray' }
{ type: 'spacer' }
```

Цвета — из палитры: `accent`, `gray`, `blue`, `green`, `orange`, `red`, `purple`, `teal`, `yellow`.
Поле с `secret: true` показывается точками; значение раскрывается только по кнопке, а копирование
идёт через `fa.clipboard.copy(..., { sensitive: true })`.

Ограничения: до 400 узлов, до 300 строк в списке, до 4000 символов в строке — лишнее обрезается.

## API `fa`

```js
// Сеть — только на объявленные хосты, только https.
await fa.http.request({ url, method, headers, body })   // → { status, headers, body }
await fa.http.get(url, options)                          // → { status, headers, body, json }
await fa.http.post(url, bodyObject, options)

// Свои секреты (связка ключей), только своё пространство имён.
fa.secrets.get('token'); fa.secrets.set('token', '…'); fa.secrets.remove('token');

// Своё хранилище: любой JSON до 256 КБ.
fa.storage.get(); fa.storage.set({ seen: {} });

fa.clipboard.copy('текст', { sensitive: true, clearAfter: 45 });
fa.notify({ title, subtitle, trailing, icon, tint });
fa.openURL('https://example.com/');
await fa.exec('op', ['item', 'list', '--format=json'], { timeout: 60 });  // → { status, stdout, stderr }
fa.isInstalled('op');
fa.autofill({ username, password });
fa.base64('строка');
// Перерисовать вкладку прямо сейчас: покажите «загружаем», а потом делайте долгий вызов.
fa.update();
// Заполнить свою же настройку. Поле типа host применяется только после подтверждения
// пользователем — адрес определяет, куда плагину вообще можно обращаться.
fa.settings.set('site', 'company.atlassian.net');
fa.log('что угодно');     // видно в Настройки → Плагины → Журнал плагина
```

Если права нет — вызов бросает исключение (`fa.exec` и `fa.http` отклоняют промис). Это можно поймать
и показать понятное сообщение.

Лимиты: тело запроса ≤ 1 МБ, ответ ≤ 5 МБ, таймаут запроса 20 с, до 20 заголовков; `exec` — до 24
аргументов, таймаут до 60 с, вывод до 2 МБ; хранилище ≤ 256 КБ; один вызов плагина — не дольше 45 с.

Чего в песочнице нет вовсе: `fetch`, `XMLHttpRequest`, `require`, `process`, `setTimeout`,
`localStorage`, доступа к файловой системе и к объектам приложения.

## Модель безопасности

| Что | Как ограничено |
|---|---|
| Исполнение | Отдельная виртуальная машина JavaScriptCore на плагин. Плагины не видят друг друга. |
| Зависание | Непрерывный JS дольше 2 с прерывается, вызов дольше 45 с считается неотвеченным. |
| Сеть | Только `https`, только хосты из манифеста, без cookie, редиректы за пределы списка обрываются, `Set-Cookie` до плагина не доходит. |
| Секреты | Связка ключей, пространство имён по `id` плагина. Секреты из формы настроек не попадают в `env.settings`. |
| Буфер обмена | Только запись. Секретные значения помечаются `org.nspasteboard.ConcealedType` (не попадают в историю буфера) и очищаются по таймеру. |
| Программы | Короткий список известных программ, абсолютные пути, argv без оболочки, пустой ввод, урезанное окружение, запрет подмены конфигурации, таймаут с принудительным завершением. |
| Интерфейс | Плагин присылает данные, рисует хост. Нельзя нарисовать своё окно, поле ввода пароля или системный запрос. |
| Целостность | Хеш скрипта в манифесте проверяется при загрузке; изменившийся пакет теряет выданные разрешения и спрашивает согласие заново. |
| Согласие | Выдаётся по пунктам и отзывается в любой момент в **Настройки → Плагины**. Выключенный плагин не запускается вовсе. |
| Происхождение | Плагин из каталога и плагин, установленный вручную, помечены по-разному; перед установкой не из каталога приложение предупреждает, что мы его не проверяли. |
| Журнал | Каждое обращение к хосту видно пользователю в журнале плагина. |
| Адреса из плагина | `fa.settings.set` для поля типа `host` ничего не меняет сам: пользователь подтверждает новый адрес во вкладке. |

Проверить это можно самому: отладочная сборка запускается с `-debugPluginSelfTest YES`
и прогоняет 78 проверок песочницы, обоих встроенных плагинов, настоящих запусков программ
и правил доступа.

## Разработка и установка

1. Соберите папку `имя.fastplugin` с `manifest.json` и `plugin.js`.
2. Проставьте хеши: `python3 scripts/plugin_stamp.py путь/к/имя.fastplugin`.
3. **Настройки → Плагины → Установить плагин…**, выберите папку или zip, разрешите запрошенное.
4. После правки скрипта снова проставьте хеш и нажмите **Перезапустить** в карточке плагина.

Полезное при отладке: `fa.log(...)` пишет в журнал плагина (Настройки → Плагины → Журнал плагина),
ошибки выполнения показываются прямо во вкладке.

Данные плагина лежат в `~/Library/Application Support/FastAction/PluginData/<id>/`, секреты —
в связке ключей, разрешения — в `plugin-grants.json`. Удаление плагина стирает всё перечисленное.

## Каталог

Список опубликованных плагинов лежит в `plugins.json` в репозитории проекта; приложение
скачивает его и показывает в **Настройки → Плагины**. Человеческая версия того же списка —
[docs/catalog.md](catalog.md): описания от авторов, ссылки на репозитории, кто что просит.

Чтобы попасть туда, выложите архив плагина в релиз своего репозитория и пришлите pull request
с записью в `plugins.json` (поля и чеклист ревью — на той же странице). Хеш архива из индекса
приложение сверяет перед установкой: подменить выложенный архив после ревью не получится.
